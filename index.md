# mlr3survival

![](reference/figures/warning.png) This package is **under development**
and it does not yet replace *mlr3proba*

Package website: [release](https://mlr3survival.mlr-org.com/)

Survival analysis with ‘mlr3’.

## Installation

Install the development version from GitHub:

``` r

# install.packages("pak")
pak::pak("mlr-org/mlr3survival")
```
